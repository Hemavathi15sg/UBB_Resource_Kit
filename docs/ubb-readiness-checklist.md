# GitHub Copilot Usage-Based Billing (UBB) Readiness Checklist

## Understand the Changes

- [ ] Review GitHub's transition from PRUs to AI Credits
- [ ] Understand token-based consumption (Input, Output, Cached Tokens)
- [ ] Identify which Copilot features consume AI Credits
- [ ] Understand model-specific pricing differences

---

## Assess Current Usage

- [ ] Identify high-usage teams and users
- [ ] Review current Copilot adoption across the organization
- [ ] Analyze usage patterns for Chat, Agents, Code Review, and CLI
- [ ] Identify potential power users

---

## Configure Governance

- [ ] Define Enterprise-level additional spend budget
- [ ] Create Cost Center/Organization budgets
- [ ] Configure User-level budgets
- [ ] Establish budget alert thresholds

---

## Monitoring & Reporting

- [ ] Enable usage monitoring dashboards
- [ ] Review usage reports regularly
- [ ] Track heavy consumers and trends
- [ ] Establish monthly governance reviews

---

## Developer Enablement

- [ ] Educate teams on AI Credits
- [ ] Train users on model selection
- [ ] Share prompt engineering best practices
- [ ] Publish internal Copilot usage guidelines

---

## Go-Live Readiness

- [ ] Validate budget configurations
- [ ] Review governance policies
- [ ] Define escalation process for budget increases
- [ ] Communicate changes to all stakeholders
