# GitHub Copilot Usage-Based Billing (UBB)

GitHub Copilot Usage-Based Billing (UBB) is GitHub's consumption model based on AI Credits and token usage.

This repository helps understand the UBB transition, what affects consumption, and how to prepare teams with readiness, optimization, and governance guidance.
